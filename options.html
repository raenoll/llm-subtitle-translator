LLM Subtitle Translator

用大语言模型把 Netflix / Disney+ / Prime Video / YouTube 等平台的字幕实时翻译成你看得懂的语言。

Google Translate v3 已在 1.17.0 移除。你之前选的是它，现在已自动改用 Gemini，保存过的 Service Account JSON 也已从扩展里删除。请在下面确认 Gemini 的 API Key 已填好并点「测试连接」，也可以改选其他后端。

1. 翻译后端

每个后端保存各自的 key，切换后端不会覆盖。
上方选择「自定义」后，这里填写的名称会原样发给后端。
即模型的 temperature：数值越低译文越稳定，越高越随意。默认 0.2；填 0 会按 0.2 处理。

基础模式：Google Translate 只负责把句子译出来，不接受任何指令。它速度快、结果稳定，也不会把台词当成对话来回答；但同一视频内保持人名一致、「上下文行数」和回答不合格时的重问对它都不起作用。想要这些功能请改用 Gemini、OpenAI、Claude 或自定义模型。

Google Cloud Console → APIs & Services → Credentials → Create credentials → API Key。 确保已启用 Cloud Translation API。

2. 翻译行为

发送给模型的最近翻译行数，用于保持语气和代词一致。
打开后在视频页面 DevTools Console 会看到 [subtitle-translator] 日志，用于排查没检测到字幕的情况。

3. 不翻译的语言

字幕被识别为下列语言时，直接显示原文、不调用翻译 API（省钱、省延迟）。点击常用语言加入列表；或在底部输入框添加自定义。

扩展按字符集自动识别（CJK / 假名 / Hangul / 西里尔字母 / 拉丁字母）。自定义条目只对扩展能识别出的语言生效； 大多数拉丁语族（英、西、法、德、葡、意…）会统一被识别为 English，此时仅加 English 即可。

4. 译文样式

填任意 CSS font-family 值，留空则使用系统默认。字体始终使用这里的设置—— 网站自身的字幕字体（Netflix Sans、Roboto 等）不含中日韩字形，继承过来对译文没有意义。
嫌字太粗就往下调。实际可选的档数取决于字体本身——浏览器会把请求的 字重映射到该字体真正带有的最接近字面，而不是凭空加粗。PingFang SC 有 6 个字面 （极细～中黑，最重只到 600，选 700 只会落回 600）；Heiti SC 只有 2 个（细体 / 中黑）， SimHei 之类单字面字体则完全不受影响。想要更细的中文黑体，PingFang SC 的 100–300 是 本机能拿到的最细的一档。原文行会自动比译文轻一档。

6. 使用说明

        
    
          
  1. 在 Chrome 地址栏打开 chrome://extensions，开启「开发者模式」。
    2. 
          
  2. 点击「加载已解压的扩展程序」，选择这个项目文件夹。
    3. 
          
  3. 拿到 Gemini / OpenAI / Claude 的 API Key 填在上面，点「测试连接」。
    4. 
          
  4. 打开 Netflix / Disney+ / Prime Video / YouTube 播放视频，在平台内先把原文字幕开起来（比如英文字幕）。
    5. 
          
  5. 扩展会隐藏原生字幕并在底部覆盖翻译版本，可选同时显示原文。
    6. 
        

        

          翻译是通过大模型完成的，会产生 API 调用费用；建议使用 Gemini flash / gpt-4o-mini / claude-haiku 等成本低的模型。
