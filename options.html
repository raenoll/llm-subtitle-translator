LLM Subtitle Translator

用大语言模型把 Netflix / Disney+ / Prime Video / YouTube 等平台的字幕实时翻译成你看得懂的语言。

1. 翻译后端

每个后端保存各自的 key，切换 provider 不会覆盖。
Google Cloud Console → APIs & Services → Credentials → Create credentials → API Key。 确保已启用 Cloud Translation API。
Google Translate v3 专属设置
v3 不支持 API Key（会报 401）。需要 Service Account：IAM & Admin → Service Accounts 新建一个，授予 Cloud Translation API User 角色，Keys → Add Key → Create new key → JSON，把下载的文件内容整个粘进来。扩展本地用 Web Crypto 签 JWT 换 access token，JSON 只存在 chrome.storage.sync 里。
用 translation-llm 时必须是 us-central1；普通 NMT 可用 global。
默认 general/translation-llm（Gemini 驱动，质量最好）；也可填 general/nmt，或完整路径 projects/…/models/…。

2. 翻译行为

发送给模型的最近翻译行数，用于保持语气和代词一致。
打开后在视频页面 DevTools Console 会看到 [subtitle-translator] 日志，用于排查没检测到字幕的情况。

3. 不翻译的语言

字幕被识别为下列语言时，直接显示原文、不调用翻译 API（省钱、省延迟）。点击常用语言加入列表；或在底部输入框添加自定义。

扩展按字符集自动识别（CJK / 假名 / Hangul / 西里尔字母 / 拉丁字母）。自定义条目只对扩展能识别出的语言生效； 大多数拉丁语族（英、西、法、德、葡、意…）会统一被识别为 English，此时仅加 English 即可。

4. 译文样式

开启：沿用当前流媒体网站正在渲染的字幕字体与字号，自动继承你在 Netflix / YouTube 等平台里设的字幕大小，并随播放器尺寸变化。读不到时 （平台字幕关闭、或字幕烧录在画面里）回退到下面的自定义设置。
关闭：改用下面自定义的字体与字号。
西方网站的字幕字体（Netflix Sans、Roboto 等）不含中日韩字形， 所以开启后字号照常继承，但译文的字体仍需要下面填一个中文字体—— 浏览器会按字形逐个回退：英文原文用网站字体，中文译文用你填的字体。
填任意 CSS font-family 值。留空则使用系统默认。
以 1080p 视频为基准自动等比缩放——4K 全屏约 2 倍，720p 窗口约 0.67 倍。

5. 使用说明

  1. 在 Chrome 地址栏打开 chrome://extensions，开启「开发者模式」。
  2. 点击「加载已解压的扩展程序」，选择这个项目文件夹。
  3. 拿到 Gemini / OpenAI / Claude 的 API Key 填在上面，点「测试连接」。
  4. 打开 Netflix / Disney+ / Prime Video / YouTube 播放视频，在平台内先把原文字幕开起来（比如英文字幕）。
  5. 扩展会隐藏原生字幕并在底部覆盖翻译版本，可选同时显示原文。

翻译是通过大模型完成的，会产生 API 调用费用；建议使用 Gemini flash / gpt-4o-mini / claude-haiku 等成本低的模型。
